# SeoulHere 캡처 기록

- 원본: `seoulhere/src/main/front`의 React 빌드 화면
- 게시판, 프로필, 찜 목록, 내 코스: 캡처용 가상 계정 및 API 응답 사용
- 실제 사용자 정보나 운영 DB는 사용하지 않음
- TMAP 서비스 만료로 이동 시간은 캡처용 예시 값 사용
- 포트폴리오의 OpenLayers 지도는 OSM/Valhalla 보행 경로를 사용한 별도 미리보기이며, 원래 프로젝트의 경로 API는 TMAP
